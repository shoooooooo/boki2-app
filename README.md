# 簿記の小さな練習帳

`index.html` をブラウザで開くと使えます。インストール・ビルド・外部サーバー・インターネット接続は不要です。フォルダー内のファイルをまとめて保持してください。

1. 単元トップの「解説から始める」で考え方を読む。
2. 「問題を解く」で仕訳の科目と金額、または計算の答えを入力する。
3. 「採点する」で正解と解説を確認する。未入力・不正な金額は採点しない。
4. 「復習」に誤答と「答えを見る」で確認した問題が残る。正答すると外れる。正答1回で習得を保証するものではありません。

仕訳は必要な行だけ入力し、残りは科目・金額とも空欄にします。行順は自由で、同じ科目を分割しても採点できます。部分点はありません。金額は円や符号のない整数で、全角数字・カンマも使えます。採点後の入力は固定され、「もう一度解く」で空欄からやり直せます。

## 今回の教材

「有形固定資産（基本）」24問（仕訳17・計算7）と解説4節。取得6問、年間償却5問、月割5問、期首売却3問、期中売却5問。3級と重なる基礎を2級学習の入口にしています。2級全範囲の教材ではありません。

- 会計期間は4月1日〜翌3月31日。定額法・間接法、取得月と売却月を含む月割。残存価額と耐用年数は各問に記載します。土地は非償却です。
- 期中売却は当期分の償却を先に記帳し、その後の売却仕訳のみを答えます。すべて円単位で割り切れる数値です。
- 税・圧縮記帳・リース・定率法・生産高比例法・除却・買換え・建設仮勘定・資本的支出・割賦購入は対象外です。
- 問題と金額はこのアプリ用の創作です。取得原価の原則は[ASBJ「中小企業の会計に関する指針」固定資産の取得価額](https://www.asb-j.jp/jp/wp-content/uploads/sites/4/sme18.pdf)を参考にしています。問題文の条件を優先し、実務・税務判断には使いません。

## 保存と端末の違い

復習対象はlocalStorageの `boki2-study.review.fixed-assets` キーに保存します。保存形式は `schemaVersion: 1`、データ版は `fixed-assets-v1`。途中の入力・閲覧位置・得点は保存しません。別の端末やブラウザへは同期しません。複数タブで開くと後から保存した内容が優先されます。

ブラウザの保存許可や `file://` の扱いによって保存できない場合があり、画面の保存状態に表示します。その場合も学習は続けられますが、再読込で今回の復習記録が失われます。ファイルの移動で保存領域が変わる場合もあります。保存データが壊れている、または未対応版の場合は元データへ上書きせず保護します。「この単元の保存データを初期化」を確認して実行すると、このキーだけを削除します。他のブラウザデータは削除しません。

PCはChrome/Edge等でHTMLを直接開けます。スマホ向けの幅にも対応しますが、スマホのファイルアプリがHTMLをプレビューするだけの場合はJavaScriptが動きません。JavaScriptを実行できるブラウザで開いてください。実機スマホのローカルファイル読込は機種・OSに依存します。相対パスだけで動くので、静的ホスティングでもそのまま使えます。

## ファイルと追加方法

| 用途 | ファイル |
|---|---|
| 入口と画面 | `index.html`・`app.js`・`styles.css` |
| 採点と保存 | `core.js` |
| 教材データ | `data/fixed-assets-v1.js` |
| 自動チェック | `tests/run-checks.js` |

英小文字とハイフンで命名し、用途で分けています。入口のREADMEは例外です。本体はこの場所の現行版を保守し、問題データと保存形式に版を付けます。旧版はありません。将来データ改版時は別の版ファイルを追加し、このREADMEの表で最新版と旧版を区別します。

問題はデータファイルのquestionsへ追加します。IDは一意で再利用せず、lessonId・type・prompt・conditions・answer・facts・explanationを用意します。factsはテストの検算用で、採点にはanswerを使用します。科目はaccountsに登録します。新単元の追加には読込・画面側の対応も必要です。現在のチェックは初版24問の配分を検査するので、追加時には意図した件数へ更新してください。

## 検証

このフォルダーで `node tests/run-checks.js`。Node.js標準機能だけを使い、24問の検算・採点・保存失敗・データ保護を確認します。ブラウザの見た目や操作は別に確認してください。

保存失敗を安全に確認する専用クエリとして、`index.html?storage=deny`（読込拒否）と `index.html?storage=quota`（書込拒否）を用意しています。この2モードは実際の保存領域へ触れません。通常利用はクエリなしで開きます。
